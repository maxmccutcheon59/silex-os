# Doctrine

Become the default layer other software and robots must use to change the physical world.

1. No action without a live writ.
2. A writ is a capability: actor, actions, resource, expiry, revoke.
3. The ledger is append-only and hash-chained.
4. Adapters execute. The kernel authorizes and records.
5. Quality failure is a halt, not a close.
6. Never close a job the runtime did not finish.
